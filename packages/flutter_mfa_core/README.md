# flutter_mfa_core

Pure Dart core of [flutter_mfa](https://github.com/Breaktroughf1/flutter_mfa): TOTP/HOTP generation (RFC 6238/4226), server-side verification with replay protection and attempt limiting, `otpauth://` URIs, Base32 and the encrypted backup format. No Flutter dependency, so it runs on Dart servers.

> **Status:** in development towards v0.2.0. Not yet published. APIs may change.

Built and maintained by **BreaktroughF1 LLP** in collaboration with **ARDC, CHRIST (Deemed to be University)**. MIT licensed.

Security model and design: see the [project docs](https://github.com/Breaktroughf1/flutter_mfa/tree/main/docs).
