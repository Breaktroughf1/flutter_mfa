# Changelog

All notable changes to this package are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and this package uses
[Semantic Versioning](https://semver.org) (0.x: a minor bump may break).

## 0.3.0

- **Breaking:** requires Dart 3.13 and Flutter 3.47 or later (was 3.9 / 3.35;
  ADR-0015). Android minSdk 24 and iOS 15 are unchanged.
- **Breaking:** the theme adapters target Flutter's new design-system packages.
  `package:flutter_mfa_ui/material.dart` now extends `ThemeData` from
  `package:material_ui`, and `package:flutter_mfa_ui/cupertino.dart` extends
  `CupertinoThemeData` from `package:cupertino_ui`. Both SDK libraries
  (`package:flutter/material.dart`, `cupertino.dart`) are deprecated since
  Flutter 3.47. Apps still on them: move to `material_ui` / `cupertino_ui`,
  stay on 0.2.x, or build an `MfaThemeData` directly.
- Localisation: register `MfaLocalizations.delegate` next to your design
  system's delegates, for example
  `[MfaLocalizations.delegate, ...GlobalMaterialLocalizations.delegates]` with
  `material_ui`. The generated `MfaLocalizations.localizationsDelegates` list
  still uses `flutter_localizations`' deprecated Material and Cupertino
  delegates (generated by Flutter's `gen-l10n`), so it only fits apps on the
  old SDK libraries.
- `EnrollmentQrView` uses `qr` 4 (error correction level M and the 4-module
  quiet zone are unchanged; the widget test still decodes the rendered code
  back to the exact URI). New dependencies: `material_ui`
  ^1.4.0 and `cupertino_ui` ^1.1.1 (BSD-3-Clause, Flutter team).
- Accepts `flutter_mfa_core` 0.2 or 0.3 (`>=0.2.0 <0.4.0`).

## 0.2.0 - 2026-11-08

- `MfaTheme` and `MfaThemeData` (light and dark defaults meeting WCAG AA),
  with Material and Cupertino adapters in `material.dart` and `cupertino.dart`.
- `MfaLocalizations` (English, Hindi, Arabic). Widgets fall back to English
  when the delegate is not registered; `mfaStrings(context)` gives custom
  builders the same fallback.
- `OtpCodeField`: one accessible text field drawn as digit boxes, with
  paste, one-time-code autofill, numeric keyboard and announced errors.
- `OtpCodeDisplay` (grouped, read digit by digit, tap to copy, hidden mode),
  `OtpCountdownRing` and `MfaStatusBadge` (icon and text).
- `OtpAccountTile` and `OtpAccountList` (driven by `MfaClient.watchAccounts()`).
- `MfaPressable`: keyboard-reachable tap target (Tab, Enter or Space, focus
  outline) used by every interactive part of these widgets.
- `EnrollmentQrView`: enrolment QR code, grouped setup key with opt-in copy,
  privacy warning.
